# Gallery captures

- `watch-map.png`: the actual `trail-map` host binary, receiving indexed artwork
  generated from the public Monaco example through the production wire decoder.
- `stopwatch.png`, `intervals.png`, `counter.png`: actual Rust app host binaries,
  captured by `tools/check_tools.py`.
- `ios-map.png`: the built SwiftUI companion in the iOS simulator.
- `android-map.png`: the built Android companion in the Android emulator.

These are software captures, not camera photographs of physical hardware.
The webpage's control preview is separately implemented browser interaction.
Map data © OpenStreetMap contributors, ODbL 1.0; see `examples/source.json`.
