# Watch SDK

The stock firmware stub, app loader, Rust app SDK, host simulator and BLE CLI.
Based on [cmf-tech-community/cmf-watch-sdk](https://github.com/cmf-tech-community/cmf-watch-sdk), under the retained MIT license.

Start with [the workbench installation guide](../../docs/getting-started.md),
then [the app guide](docs/app-guide.md). The ROM addresses target JX402 firmware
1.0.0.73. Other models and firmware versions need a separate port.
